# Plan: Dockerize the Marketplace Personal Account App

## Goal
Containerize the React + Vite + TypeScript app with json-server backend using Docker, so it can be run with a single command.

## What needs to be done

### 1. Create `.dockerignore`
Exclude node_modules, dist, .git, IDE files, etc. from Docker build context.

### 2. Create `Dockerfile` (multi-stage build)
- **Build stage**: Node 20-alpine, install deps, build Vite app
- **Serve stage**: nginx:alpine, copy dist, configure nginx to serve static files and proxy /api to backend
- Set `VITE_API_URL=http://backend:3000` at build time

### 3. Create `docker-compose.yml`
Two services:
- **frontend**: port 5173, built from Dockerfile
- **backend**: port 3000, uses node image with json-server, mounts db.json

### 4. Update `src/shared/variables.ts`
Replace hardcoded `http://localhost:3000` with `import.meta.env.VITE_API_URL ?? 'http://localhost:3000'`.

### 5. Update `README.md`
Add a Docker section with instructions:
- Prerequisites (Docker, Docker Compose)
- Run: `docker compose up`
- Access: http://localhost:5173
- Build only: `docker compose build`
- Stop: `docker compose down`

## Files to create/modify
- **Create**: `.dockerignore`, `Dockerfile`, `docker-compose.yml`
- **Modify**: `src/shared/variables.ts`, `README.md`

## Fix: Routing/API issue in container

### Problem
Frontend bundle contains hardcoded `http://backend:3000` as API URL. Browser on host machine cannot resolve Docker hostname `backend` → `ERR_NAME_NOT_RESOLVED`.

### Root cause
`VITE_API_URL` was set to `http://backend:3000` at build time and baked into the JS bundle. Browser makes direct requests to `backend:3000` which is only resolvable inside Docker network.

### Fix (Part 1)
Change `API_URL` to relative path `/api`. Nginx already proxies `/api/` → `backend:3000`. This works both inside Docker (nginx → backend) and from browser (browser → nginx → backend).

**File: `src/shared/variables.ts`**
- Change `export const API_URL = import.meta.env.VITE_API_URL ?? 'http://localhost:3000';`
- To: `export const API_URL = '/api';`

**No changes needed to nginx.conf** — it already has `location /api/ { proxy_pass http://backend:3000/; }`.

### Problem (Part 2)
After Part 1 fix, 502 Bad Gateway — nginx can't connect to backend. Backend container runs json-server but it listens only on `::1` (IPv6 loopback), not on `0.0.0.0`. Docker DNS resolves `backend` to container IP, but connection is refused.

### Fix (Part 2)
Add `--host 0.0.0.0` flag to json-server command in `docker-compose.yml`.

**File: `docker-compose.yml`**
- Change: `command: npx json-server --watch /app/db.json --port 3000`
- To: `command: npx json-server --host 0.0.0.0 --watch /app/db.json --port 3000`

### Verification
```bash
docker compose down && docker compose up --build -d
# App should work at http://localhost:5173/
```
